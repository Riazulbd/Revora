# Release signing

The Android release build is signed with a keystore that is **not** committed
(`.gitignore` excludes `*.keystore`). A development release key was generated at:

```
credentials/revora-release.keystore
```

It lives outside `android/` on purpose: `expo prebuild --clean` deletes that
directory, and a keystore inside it would vanish on the next prebuild.

| Property        | Value             |
| --------------- | ----------------- |
| Key alias       | `revora`          |
| Store password  | `revora-release`  |
| Key password    | `revora-release`  |
| Validity        | 10,000 days       |

These are **development credentials**. Before publishing to Google Play, replace
them with a key you control and keep off this machine.

## How the signing config is applied

`android/` is regenerated by `expo prebuild`, so editing `app/build.gradle` by
hand would be undone on the next prebuild. The configuration is applied by the
config plugin at `plugins/withReleaseSigning.js`, which writes four gradle
properties and points `buildTypes.release` at them.

Override any of them from the environment:

```bash
REVORA_RELEASE_STORE_FILE=/secure/path/upload.keystore \
REVORA_RELEASE_STORE_PASSWORD=… \
REVORA_RELEASE_KEY_ALIAS=upload \
REVORA_RELEASE_KEY_PASSWORD=… \
npx expo prebuild --platform android --clean
```

## Building

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@17
export ANDROID_HOME="$HOME/Library/Android/sdk"

npm run verify                                  # types, lint, tests
npx expo prebuild --platform android --clean
./android/gradlew -p android assembleRelease    # APK  → android/app/build/outputs/apk/release/
./android/gradlew -p android bundleRelease      # AAB  → android/app/build/outputs/bundle/release/
```

Google Play requires the **AAB**. The APK is for direct installation and testing.

## Recommended for Play

Enrol in **Play App Signing** and upload with an *upload key* rather than the app
signing key. Google then holds the signing key, and a lost upload key can be
reset — a lost app signing key cannot.
